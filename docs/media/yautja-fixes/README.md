# Yautja regression review media

These are sprite inspection sheets, not screenshots captured from a running game.

- `weapon-sprites.png`: object, one-handed and two-handed weapon states in the four directions. The states were imported without pixel changes from CMSS13 revision `52be8a8ceeb165c6a0becc77ecc3c9a644b88fd2`; `Tools/_CMU14/Yautja/import_weapon_sprites.py --check` checks the imported pixels and state metadata.
- `ronin-mask.png`: the local Ronin mask composed with the Yautja head at offsets of 0, 2 and 3 pixels. The final prototype uses the bottom row, a 3-pixel upward offset. This is a local alignment correction, not a claim that CMSS13 contains an identical Ronin mask state.

See the original [weapon DMI](https://github.com/cmss13-devs/cmss13/blob/52be8a8ceeb165c6a0becc77ecc3c9a644b88fd2/icons/obj/items/hunter/pred_gear.dmi), [left-hand DMI](https://github.com/cmss13-devs/cmss13/blob/52be8a8ceeb165c6a0becc77ecc3c9a644b88fd2/icons/mob/humans/onmob/hunter/items_lefthand.dmi), [right-hand DMI](https://github.com/cmss13-devs/cmss13/blob/52be8a8ceeb165c6a0becc77ecc3c9a644b88fd2/icons/mob/humans/onmob/hunter/items_righthand.dmi), and the individual RSI metadata files under `Resources/Textures/_CMU14/Yautja` for source-specific credits.
